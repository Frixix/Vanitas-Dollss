# Vanitas-Dollss

Proyecto académico desarrollado junto con compañeros de la universidad, enfocado en la creación de una página web que presenta la **idea de negocio de una empresa**, su enfoque y propósito.

---

## Descripción del proyecto

Vanitas-Dollss es una página web creada como parte de un trabajo universitario cuyo objetivo principal es **plasmar y comunicar una idea de negocio**, más que desarrollar un sistema complejo.

El proyecto busca mostrar:
- El concepto de la empresa
- Su enfoque empresarial
- La propuesta general del negocio

Está pensado como una **base conceptual y visual**, no como un producto comercial terminado.

---

## Tecnologías utilizadas

El proyecto fue desarrollado utilizando tecnologías básicas de desarrollo web:

- HTML
- CSS
- JavaScript (básico, si aplica)

No se utilizan frameworks ni librerías externas avanzadas.

---

## Estructura general

El sitio web cuenta con varias páginas HTML que permiten navegar por la información de la empresa, tales como:

- Página principal
- Sección de información institucional
- Otras secciones relacionadas con la idea de negocio

Los archivos están organizados en carpetas para estilos, scripts e imágenes.
